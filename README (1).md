# Atharva Neon Multi-Page Portfolio

## Pages
- `index.html` — Home
- `resume.html` — Resume
- `biodata.html` — Personal Details and Education (includes CGPA)
- `projects.html` — Gym Membership Management System, Netflix UI Clone, Spotify UI Clone

## Run
Open `index.html` in VS Code using Live Server. All navigation links point to separate HTML files in the same folder.

## GitHub Pages
Upload the contents of this folder to the repository root. In Settings → Pages, select `main` and `/(root)`.

## Customize
Edit the `Add value` placeholders in `biodata.html` and `resume.html` with your own details.
